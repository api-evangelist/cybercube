# CyberCube

> CyberCube is a cyber risk analytics provider for the insurance industry — brokers, insurers, reinsurers and cyber ILS investors — translating cyber risk into quantified financial impact. CyberConnect is its API layer for delivering CyberCube models, insights and signals into a customer's own underwriting, exposure-management and capital-modeling workflows.

This file was generated by API Evangelist from public sources on 2026-08-11. CyberCube does not serve an llms.txt of its own (https://www.cybcube.com/llms.txt returns 404).

## What an agent should know first

- There is **no machine-readable contract** published on any public CyberCube host. No OpenAPI, no AsyncAPI, no GraphQL schema, no MCP server, no A2A agent card.
- OpenAPI almost certainly **exists but is gated**. The Atlas documentation portal bundle ships swagger-ui, swagger-client and apidom with OpenApi3 parsers compiled in — a SwaggerUI reference renderer that has nothing to render unless OpenAPI documents are fetched from the authenticated docs API. Only the distribution is closed, not the specification.
- The API reference lives inside the **login-gated Atlas documentation portal** at https://docs.atlas.cybcube.com/ — a React single-page app that bootstraps a login session against https://login.atlas.cybcube.com. Every path on that host returns the same 2,259-byte HTML shell to an anonymous client, including /openapi.json.
- The production API host **https://api.cybcube.com** is a live AWS API Gateway custom domain. Anonymous requests return `403 {"message":"Missing Authentication Token"}`. Credentials are issued through a commercial relationship; there is no self-serve signup.
- CyberCube publishes **no pricing** — every commercial path is a demo request or a sales contact.

## Products

- [Account Manager](https://www.cybcube.com/account-manager): single-risk cyber underwriting.
- [Portfolio Manager](https://www.cybcube.com/portfolio-manager): portfolio aggregation and catastrophe loss modeling.
- [Broking Manager](https://www.cybcube.com/products): broker-facing cyber placement insights.
- [Exposure Manager](https://www.cybcube.com/exposure-manager): portfolio intelligence and health assessment.
- [SPoF Intelligence](https://www.cybcube.com/spof-intelligence): catastrophe-model-integrated digital supply-chain single points of failure.
- [Industry Exposure Databases](https://www.cybcube.com/industry-exposure-databases): cyber exposure databases underpinning modeled industry loss estimates.
- [Prep Module](https://www.cybcube.com/prep-module): supplementary tool for Broking Manager.

## APIs

- [CyberConnect](https://www.cybcube.com/cyberconnect): CyberCube's API layer. Advertised capability areas are catastrophe risk management, risk scoring analysis, financial loss modeling, reinsurance modeling, SPoF intelligence, risk intelligence and threat modeling, supporting portfolio risk management, single-risk underwriting and transaction broking. Base host https://api.cybcube.com (probed, auth-gated).

## Access

## Security and compliance

- [SOC 2 Type II](https://www.cybcube.com/news/2020/07/cybercube-completes-soc-2-type-ii-certification-demonstrating-level-of-customer-data-security): completed 2020-07-27, announced on CyberCube's own newsroom.
- No trust center, no /security page, no /compliance page, and no /.well-known/security.txt on any host.
- Domain posture (probed 2026-08-11): TLS 1.3 on www.cybcube.com and api.cybcube.com, HSTS on the marketing host, CAA records present, SPF present, DMARC present with policy `quarantine`, DNSSEC not enabled.

## Disambiguation

- CyberCube Analytics operates **cybcube.com** (no "er"). The domain **cybercube.com** is an unrelated parked host serving an "Under Construction" page on every subdomain and is not CyberCube.
- "CyberConnect" is also the name of an unrelated web3 social-graph protocol (github.com/cyberconnecthq, npm `cyberconnect`). Those packages are **not** CyberCube client libraries.
